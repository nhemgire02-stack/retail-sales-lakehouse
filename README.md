# Retail Sales Lakehouse

A beginner-to-production-style Data Engineering project implementing
a metadata-driven Retail Sales Lakehouse.

## Project Goal

Build a data pipeline that processes retail sales data through
Bronze, Silver, and Gold layers.

## Technologies

- Python
- SQL
- PySpark
- Delta Lake
- Azure Data Lake Storage Gen2
- Azure Databricks
- Azure Data Factory
- Azure Key Vault
- Git
- GitHub
- pytest

## Architecture

CSV Files
    ↓
Landing
    ↓
Bronze
    ↓
Silver
    ↓
Gold
    ↓
Analytics
